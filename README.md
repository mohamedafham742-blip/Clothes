# Clothes - UMAR TEX E-Commerce Website

A responsive clothing e-commerce website for **UMAR TEX**, featuring a product showcase, brand presentation, and authentication pages.

## 📌 Features

- **Home Page (`tex.html`)**: Landing page with brand introduction and navigation.
- **Shop Catalog (`shop.html`)**: Product grid displaying shirts, t-shirts, jerseys, trousers, and baby wear with pricing.
- **About Us (`about.html`)**: Company vision and background.
- **Contact Page (`contact.html`)**: Contact details and query form.
- **Authentication (`login.html`, `create.html`)**: User login and registration pages.
- **Styling (`tils.css`)**: Custom CSS styles.

## 📂 Project Structure

```
clothes/
├── about.html          # About us page
├── contact.html        # Contact us form & info
├── create.html         # Sign up / registration
├── login.html          # Login page
├── shop.html           # Product showcase & catalog
├── tex.html            # Main home / landing page
├── tils.css            # Stylesheet
├── *.jfif / *.jpg / *.svg # Product images & graphics
└── README.md           # Documentation
```

## 🚀 How to Run

Open `tex.html` in any web browser (Chrome, Edge, Firefox, etc.) or launch via VS Code Live Server.
